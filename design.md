# Identidade visual do CRM

Regra: **todas as telas do projeto seguem este arquivo.** Nada de estilo inventado fora daqui.

## Clima

Ferramenta profissional, limpa e confiante. Um produto, não um template.

## Cores

| Uso | Cor |
| --- | --- |
| Fundo da página (claro levemente quente) | `#FAFAF7` |
| Superfícies (cartões, barras, campos) | `#FFFFFF` |
| Borda sutil | `#E6E4DE` |
| Texto principal (grafite) | `#17181C` |
| Texto de apoio | `#6B6E76` |

### Cor de destaque

Uma só, para ações e elementos ativos: **azul-cobalto `#1D4ED8`**, com hover mais escuro `#1E40AF`.
Nenhuma outra cor de marca no projeto.

### Cores das etapas do funil

Usadas **somente** onde a etapa é o assunto — nas etiquetas de etapa e nos números do painel do funil. Em nenhum outro lugar:

| Etapa | Cor |
| --- | --- |
| novo | `#64748B` |
| em contato | `#D97706` |
| proposta | `#7C3AED` |
| cliente | `#15803D` |

## Tipografia

**Manrope** (Google Fonts) em tudo.
Títulos em peso forte (700/800), textos em peso normal (400/500).
Tamanhos generosos e hierarquia clara: o título tem que ser visivelmente maior que o texto.

## Formas e espaço

- Cantos levemente arredondados: **10px**.
- Bordas visíveis (`#E6E4DE`) em vez de sombras pesadas.
- Bastante respiro entre os elementos.

## Proibido

- Gradientes.
- Efeito de vidro / desfoque.
- Emojis na interface.
- Sombras exageradas.
- Animações chamativas.

Se a tela parecer template de IA, está errado.
